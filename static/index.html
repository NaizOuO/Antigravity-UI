本地模型伺服器
本地模型

用你電腦上的模型回答（不用網路、不用額度）。先安裝並開啟 Ollama（網址 http://localhost:11434/v1）或 LM Studio（http://localhost:1234/v1）， 模型名稱用逗號分隔，例如 qwen3:8b, qwen3:14b，儲存後會出現在模型選單的「本地 · …」。第一次使用會詢問要不要下載 Antigravity SDK（約 90 MB）。 小模型比較會寫錯工具呼叫，建議用支援工具呼叫的模型（例如 Qwen3）。

執行指令與 Lumina Code

一般對話和專案預設是「💬 對話模式」：AI 只能讀檔、用內建工具讀 PDF、把檔案寫到 output，不能執行指令。 要讓 AI 改程式、執行指令，請切到左上角的「要讓 AI 改程式、執行指令，請在專案設定切換成「🛠 工作模式」並綁定資料夾：lt;/> Code」並加入工作資料夾：執行指令前會跳出授權卡，每輪都有檢查點可以復原。 刪除資料夾、改系統設定、碰密碼與金鑰等操作一律擋下。注意：允許 python、powershell 等於讓 AI 在你的電腦上做任何事，請看過內容再允許。

產生 PDF 後讓模型檢查成品

PDF 編譯好後，把每一頁轉成圖片讓模型「看成品」：檢查頁數是否符合要求、版面有沒有跑掉、公式（例如括號位置）與內容有沒有錯，有問題就自動修正再重新產生。模型只看原始碼時常看不出這些問題。會多花一點時間與額度。

用量

額度不足提醒

目前模型那一組的 5 小時或每週額度剩下低於這個比例時，上方會出現提醒，避免趕作業時突然被限流。

資料

匯出目前對話

存到 output 資料夾，可以放進 Notion、Obsidian 或報告裡。

備份全部資料

把對話、專案（含上傳的檔案與記憶）和設定打包成一個 zip，存到 output 資料夾。換電腦時很方便。

匯入備份

只會補上目前沒有的對話、專案和設定，已經存在的不會被覆蓋。

agy 暫存

計算中…

agy 會為每段對話留一份暫存（讀過的 PDF 副本、生成的圖片等）。「清理」只會刪掉這個介面建立、而且對話已經不在的部分；你在終端機用 agy 的對話不會被動到。

資料夾

output、setting、data 都是你的個人資料，更新時不會被動到。

元件

需要時才下載的工具。用到時會先在對話裡詢問；也可以在這裡先安裝或移除。元件放在主目錄的 components 資料夾，不會被更新覆蓋。
