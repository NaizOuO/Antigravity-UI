# 《時之笛》風格 3D 動作冒險：規格書

> 由 Claude Code 和 Lumina 裡的 Claude（Sonnet 4.6）討論定稿，交給 Gemini 實作。
> 目標：做出「玩起來有時之笛感覺」的一小段完整體驗，品質優先於數量。分三輪做，每輪只做那一輪列的東西。

## 0. 技術

- **版本 A（Python）**：Ursina（Panda3D）。`main.py` 直接開始玩。
- **版本 B（網頁）**：Three.js（`https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`），`index.html` 開啟就能玩。
- 不要自己寫 3D 引擎或繪圖管線；用引擎內建的光源、陰影、霧、粒子、raycast。
- 遊戲邏輯（移動、碰撞、戰鬥、敵人狀態機、謎題）寫在可以**不開視窗**測試的模組（Python：`logic.py`；網頁：`logic.js`，可用 Node 或 Playwright 執行）。畫面層只負責顯示。
- 素材放 `assets/`：貼圖、圖示用生圖產生後用 `asset_import` 存進來；音效、音樂用程式合成。

| 項目 | 規定 |

| 林克比例 | 身高 1.8 單位；頭佔身高 30%；劍長 = 身高 55%；盾在左手 |

## 2. 操作與鏡頭

- WASD 移動，**相對於鏡頭方向**（W 一定往畫面前方）；滑鼠拖曳或 Q/E 轉鏡頭，左右不能顛倒。
- 第三人稱鏡頭在林克背後。**防穿牆**：每幀從林克往鏡頭理想位置做 raycast，打到牆（`wall` 標記的碰撞體）就把鏡頭放在碰撞點往林克方向 0.3 單位。
- J／滑鼠左鍵揮劍、K／空白鍵翻滾（第 0.05～0.25 秒無敵）、L 舉盾（擋正面 ±60° 內的攻擊）。
- **Z 鎖定**（按住或切換皆可），照四步做：
  1. 找距離 ≤ 12 單位、在鏡頭前方的最近敵人
  2. 鏡頭目標設為敵人位置（高度固定在敵人中心）
  3. 林克的 forward = 林克指向敵人的水平方向
  4. A／D 變成繞敵人橫移，W／S 變成靠近／遠離；敵人頭上顯示鎖定標記
  - 單元測試：敵人在林克正北 10 單位，按 Z 後 forward 應為 (0, 0, 1)（依引擎的北方軸），誤差 < 1°。
- O 吹陶笛：畫面下方出現五個音（↑↓←→A），輸入「時之歌」（→A↓→A↓）觸發效果。

## 3. 敵人

| 敵人 | 行為 |
|---|---|
| 骷髏劍士 | 靠近到 3 單位內 → 舉劍**預備 0.6 秒**（明顯姿勢）→ 砍；正面會格擋；盾擋住攻擊後骷髏硬直 1 秒，可以追打 |
| 蝙蝠 | 盤旋，每 3～5 秒俯衝一次；一擊死 |
| 食人花（第 3 輪有餘力才做） | 固定在地上，靠近時伸頭咬，咬空後硬直 |
| 頭目 | 第 1 階段：衝刺＋揮擊；血量剩一半進第 2 階段：加上地面震波（要翻滾躲） |

## 4. 回饋

- **解謎、開門、拿到道具一定要有「叮咚」上升三和弦 + 畫面小幅放大**（時之笛味道最重的地方，必做）。
- 程式合成音效：揮劍、擊中、受傷、翻滾、盧比、心、開門、陶笛五個音。
- 打擊感（第 3 輪）：hit stop 約 50 ms、敵人被擊退、鏡頭輕微震動；受傷時畫面邊緣紅閃、角色閃爍無敵 1 秒。

## 5. 三輪的內容

**第 1 輪**：移動 + 鏡頭（含防穿牆）、林克骨架與動作、單擊揮劍、翻滾、舉盾、Z 鎖定、骷髏劍士、**一個地城房間**（石牆貼圖、火把點光源、一扇鎖住的門、一把鑰匙、一隻骷髏），解鎖時「叮咚」。
- 時間不夠時的優先序：Z 鎖定、鏡頭防穿牆、肢體動作**不可省**；骷髏 AI 可以先退化成直線衝刺。

**第 2 輪**：海拉魯草原（生圖貼圖、霧、樹、草叢可砍並掉落心與盧比）、陶笛與時之歌石門、蝙蝠、村落 2 個 NPC 對話。

**第 3 輪**：三段連擊、頭目兩階段、各區音樂（切換時淡入淡出）、打擊感、標題（靜態背景）、死亡與 Game Over、暫停（Esc）、結局；最後用 `design_review` 對照本規格審查並補齊。

## 6. 每輪結束的驗收數字

用無視窗模擬（不靠截圖判斷）跑 60 秒，輸出並檢查：

| 數字 | 標準 |
|---|---|
| 林克按住 W 3 秒的移動距離 | > 5 單位，方向和鏡頭前方夾角 < 5° |
| 鏡頭靠牆時與牆的最小距離 | ≥ 0.25 單位（不穿牆） |
| 鎖定後 forward 與「指向目標」的夾角 | < 1° |
| 骷髏從預備到出手的時間 | 0.6 秒 ± 0.05 |
| 翻滾第 0.05～0.25 秒被攻擊是否扣血 | 全部 False |
| 謎題狀態圖從初始狀態能否到達通關 | True（用 BFS 走一遍門、鑰匙、開關的狀態） |
| **林克正面方向**（臉的世界座標 − 身體中心）與移動方向的夾角 | < 10°（往前、後、左、右各走一次都要檢查） |
| 盾在林克左側、劍在右側 | 用 (正面 × 上方) 的外積判斷，舉盾時盾在正面前方 |
| 鎖定時林克正面與「指向目標」的夾角 | < 10° |
| 鏡頭：按 W 走 2 秒後林克在畫面上的大小 | 變小（代表往畫面深處走，不是朝鏡頭走） |

加一個除錯模式（F1 切換）：林克腳下畫正面箭頭與 XYZ 座標軸；截圖檢查朝向時打開。

外觀與手感另外用 `run_capture` 的 `actions` 實際操作截圖：開場、轉鏡頭後移動、鎖定骷髏戰鬥、開門。
- Python 版要加 `LUMINA_SHOT_DIR` 截圖鉤子（見 run_capture 說明），不然截圖是黑的。
- 網頁版要 `venv_install playwright`；素材載入完後設 `window.__LUMINA_READY__ = true`。
