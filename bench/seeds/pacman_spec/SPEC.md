# Pac-Man 規格書

用 Python + pygame 做一個完整、好玩的 Pac-Man。主程式 `main.py`，`python main.py` 直接開始玩。
四隻鬼的追人邏輯要用自己的方式設計（不要照抄原版遊戲的程式碼），但玩起來要有原作的感覺。

## 1. 遊戲流程（狀態）

`game.state` 只會是下面其中一個：

| 狀態 | 畫面 | 時間 |
|---|---|---|
| `ready` | 迷宮、角色就位，中間顯示「READY!」，所有角色不動 | 至少 1 秒（建議 2 秒），開場和每次重生、每一關開始都有 |
| `playing` | 正常遊玩 | |
| `dying` | 鬼全部消失，小精靈播放死亡動畫（例如嘴巴張開到整個圓消失），其他東西都停住 | 至少 1 秒（建議 1.5 秒） |
| `level_clear` | 迷宮的牆閃爍幾次 | 至少 1 秒；之後進下一關（`level` + 1，豆子全部補回，角色回到起點，速度稍微變快） |

- 被抓到：`lives` − 1 → `dying` → 還有命就回到 `ready`（角色回起點，迷宮的豆子保持原樣）；沒命就 `game.over = True`，顯示 GAME OVER 與「按 R 重新開始」。
- 標題畫面（開啟程式時）：遊戲名稱、操作說明、「按 Enter 開始」。這是 `main.py` 的視窗層，不影響 `Game` 物件的狀態。

## 2. 迷宮

- 用 `game.maze`（`list[str]`）表示：`#` 牆、`.` 豆子、`o` 大力丸、` ` 空地、`-` 鬼屋的門。
- **所有不是牆的格子都要走得到**（小精靈從起點出發；鬼屋內部經由門算走得到）。不能有「看起來是通道或空地、但被牆圍住進不去」的地方；不需要的區域一律填 `#`。
- 左右各一條隧道，從一邊出去會從另一邊進來。
- 至少 4 顆大力丸、150 顆以上的豆子；鬼屋在中間，門在鬼屋上方。

## 3. 小精靈

- 沿著格子走，可以「預先轉彎」：還沒到路口就按方向，到了路口自動轉進去。
- 撞牆停下時嘴巴閉起來；移動時嘴巴開合，朝向移動方向。
- 吃豆子 10 分、大力丸 50 分。

## 4. 鬼

- 四隻鬼顏色不同（紅、粉、青、橘），有身體、裙襬波浪、會跟著移動方向轉的眼睛。
- **各自不同的追人方式**（自己設計），例如：直接追、往小精靈前方埋伏、跟另一隻鬼包夾、太近就跑開。
- `scatter`（各自回到自己的角落）和 `chase` 依時間交替。
- 開場時依序離開鬼屋（不要四隻一起出來）。
- 吃了大力丸：還沒被吃掉的鬼變成 `frightened`（深藍色、慢、隨機走），快結束時藍白閃爍；連續吃鬼 200、400、800、1600 分，吃到時在那個位置短暫顯示分數。
- 被吃掉：變成 `eaten`，**只剩眼睛，沿著迷宮的通道走回鬼屋**（不能飛、不能穿牆），進門後復活。

## 5. 音效

不用外部音效檔，用程式產生（例如用 `array` 或 `numpy` 做波形再交給 `pygame.mixer.Sound`）。
`main.make_sounds()` 回傳 dict，至少有：

| 名稱 | 什麼時候播 |
|---|---|
| `start` | 開場 READY |
| `waka` | 吃豆子（連續吃時不要疊成雜音） |
| `power` | 大力丸效果期間（迴圈播放，結束就停） |
| `eat_ghost` | 吃到鬼 |
| `death` | 死亡動畫 |

`pygame.mixer` 初始化失敗（沒有音效裝置）時遊戲仍要能玩，只是沒有聲音。

## 6. 畫面

分數、最高分（存成檔案，下次開還在）、剩餘生命（小精靈圖示）、目前關卡。

## 7. 給自動驗收用的介面

`main.py` 提供下面這些（遊戲本身也要用同一套邏輯，不能另外寫一份）：

- 常數 `TILE`（格子邊長，像素）、`PACMAN_SIZE`、`GHOST_SIZE`（碰撞方塊邊長，像素）
- `Game(seed)`：建立一局；`import main` 和建立 `Game` 都不能開視窗或初始化音效
- `game.maze`、`game.state`、`game.level`（從 1 開始）、`game.score`、`game.lives`、`game.over`
- `game.pacman`：小精靈中心點的像素座標 `(x, y)`
- `game.ghost_positions()`：4 個 `(x, y)`；`game.ghost_modes()`：4 個字串（`chase`、`scatter`、`frightened`、`eaten`；在鬼屋裡等著出來時用 `scatter`）
- `game.update(dt, direction)`：前進 `dt` 秒；`direction` 是 `(dx, dy)` 或 `None`（不按鍵）
- `game.pellets_left()`：直接數 `game.maze` 裡的 `.` 和 `o`
- `make_sounds()`：見第 5 節

## 8. 驗收

`acceptance_test.py` 是驗收測試：`.venv\Scripts\python acceptance_test.py . spec`，最後一行 `BENCH_RESULT` 每一項都要是 `true`。
自動測試測不到手感和畫面，所以另外一定要用 `run_capture` 的 `actions` 實際玩過：開場、移動轉彎、被鬼抓到、吃大力丸吃鬼，逐張看截圖確認。
